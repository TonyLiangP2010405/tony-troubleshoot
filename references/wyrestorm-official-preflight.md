# 产品资料预检规则：本地 IPAV 优先、官网补充

目标是在连接设备前获得足够的产品上下文，避免把其它型号、旧固件或通用经验误用于当前系统。研究必须定向、有限并可复核。

## 来源边界

来源按当前产品身份选择，不把 WyreStorm 官网当作所有 OEM/ODM 型号的唯一入口：

1. 当前环境提供 `$tony-skill` 时，先按该 Skill 的规范客户端执行 `health`，再用准确型号 `product` 或 `search` 检索本地 `D:\IPAV` 知识库。首次结果不清晰时最多用命中的准确型号、英文 UI 标签或协议名聚焦检索一次。
2. 记录每条本地证据的 `file`、`locator`、命中片段、文档标题/版本/日期和适用性。工程设计稿、供应商文档和未发布资料要标出性质，不能自动称为官方确认。
3. 对公开 WyreStorm 型号，再使用 `wyrestorm.com` 产品页、FAQ、Product Resources/Support Hub 及其直接链接文档补充或交叉验证。
4. 第三方论坛、经销商页面、搜索摘要和未验证转载只能作为待验证线索。

## 研究顺序

1. 确认每个在范围内的准确型号、硬件代次、产品系列、OEM/ODM/公开品牌身份、当前固件/API 版本和是否停产。型号不确定时先向客户确认，不能用相似名称代替。
2. 先在本地知识库查产品文档、设计说明、UI 标签、命令语义、固件说明和配对/升级机制；再按产品身份决定是否查询官网。
3. 对公开产品核对官网规格表、Quick Start、User Manual、Technical Reference、API/控制文档、固件、软件、驱动和发行说明。
4. 只围绕当前症状核对相关能力和限制：
   - 视频：分辨率、帧率、色深/色彩空间、HDR、HDCP、EDID、缩放、Genlock、带宽和线缆限制。
   - 音频：PCM/LPCM/Dolby/DTS、ARC/eARC、模拟音频、Dante 和采样/通道限制。
   - 网络/AV over IP：支持的交换机、组播、IGMP、VLAN、巨帧、PoE、带宽、拓扑和级联要求。
   - 控制/USB：RS232、IR、CEC、USB Host/Device、端点/Hub 限制、控制驱动和配对方式。
   - 电源/环境：DC/PoE 规格、功率预算、接地、工作环境和线缆类别/长度。
5. 查找与当前固件及症状有关的已知限制、默认值、兼容性、升级注意事项和停产资料。来源没有发布的内容不得猜测。
6. 在 `wyrestorm-official-research.md` 分别写出本地知识库状态、官网状态、来源等级、哪些事实改变了分类/查询选择，以及仍缺什么。

## 停止条件

当每个范围内型号已有足够、可定位的产品上下文，且与当前症状有关的能力、限制、固件和配置要求已核对，即停止。OEM/ODM 或官网不可访问时，若本地资料已建立适用性，可将官网状态标为 `unavailable` 并继续；不要为了过门禁反复访问注册墙、选国页或无关市场页面。

## 证据与安全

- 每条来源记录标题、URL、访问时间、型号/版本适用性和关键事实；网页可能变化，因此不能只写页面名称。
- 产品资料不等于命令执行授权。命令还要通过静态文档或同固件 Web UI 的受控只读证据建立安全依据。
- 发现官网固件更新不等于应该升级；升级、安装软件或改变配置仍需文档核对和用户对具体动作的明确授权。
- 官网无法访问时如实标记 `unavailable`，列出未核对项，并继续使用适用的本地 IPAV/ODM 资料和客户提供资料；若这些来源仍无法判断命令适用性，则按原安全规则阻塞相应设备查询。
