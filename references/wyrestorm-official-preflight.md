# WyreStorm 官方资料预检规则

目标是在连接设备前获得足够的产品上下文，避免把其它型号、旧固件或通用经验误用于当前系统。研究必须定向、有限并可复核。

## 来源边界

优先使用 `wyrestorm.com` 的准确产品页、FAQ、Product Resources/Support Hub，以及从这些官方页面直接链接的 WyreStorm 文档下载位置。第三方论坛、经销商页面、搜索摘要和未验证转载不能作为确认事实；如为发现线索而查看，只能记录为待官方文档验证的推论。

## 研究顺序

1. 确认每个在范围内的准确型号、硬件代次、产品系列、当前固件/API 版本和是否停产。型号不确定时先向客户确认，不能用相似名称代替。
2. 找到对应产品页和 Product Resources 条目，核对规格表、Quick Start、User Manual、Technical Reference、API/控制文档、固件、软件、驱动和可用的发行说明。
3. 只围绕当前症状核对相关能力和限制：
   - 视频：分辨率、帧率、色深/色彩空间、HDR、HDCP、EDID、缩放、Genlock、带宽和线缆限制。
   - 音频：PCM/LPCM/Dolby/DTS、ARC/eARC、模拟音频、Dante 和采样/通道限制。
   - 网络/AV over IP：支持的交换机、组播、IGMP、VLAN、巨帧、PoE、带宽、拓扑和级联要求。
   - 控制/USB：RS232、IR、CEC、USB Host/Device、端点/Hub 限制、控制驱动和配对方式。
   - 电源/环境：DC/PoE 规格、功率预算、接地、工作环境和线缆类别/长度。
4. 查找与当前固件及症状有关的已知限制、默认值、兼容性说明、升级注意事项和停产资料。只记录官网实际发布的内容，不猜测缺失的 release note。
5. 在 `wyrestorm-official-research.md` 写出哪些事实改变了分类、查询选择或风险判断，以及哪些内容仍缺失。

## 停止条件

当每个在范围内的 API 配置已有准确官方产品上下文，且与当前症状有关的能力、限制、固件和配置要求已核对，即停止研究。不要为了“更全面”继续浏览无关产品、市场页面或案例文章。

## 证据与安全

- 每条来源记录标题、URL、访问时间、型号/版本适用性和关键事实；网页可能变化，因此不能只写页面名称。
- 官方产品背景不等于可执行命令授权。只有准确 API 文档明确证明为只读的命令才可执行。
- 发现官网固件更新不等于应该升级；升级、安装软件或改变配置仍需文档核对和用户对具体动作的明确授权。
- 官网无法访问时如实标记 `unavailable`，列出未核对项，并继续使用客户提供的准确资料；若因此无法判断 API 适用性，则按原安全规则阻塞设备连接。
