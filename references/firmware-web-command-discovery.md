# 固件 Web UI 命令发现与安全分级

本规则用于静态 API 手册可能落后于设备固件、某些主开关或状态仅由设备自身 Web UI 使用的情况。目标是补齐只读可见性，不是把前端字符串自动变成可执行 API。

## 启动时建立 Web UI 会话

1. 让用户在自己的浏览器打开每台当前相关设备或控制器的准确 Web UI，并由用户自行完成登录。不要索要、代填、复制或保存用户名、密码、Cookie、令牌、授权头或 CSRF token。
2. 用户登录后确认页面对应的地址、型号、序列号或设备名，并明确允许 agent 使用当前页面会话做只读诊断。每台设备分别记录到 `web-ui-session-ledger.csv`；记录 URL 前移除 userinfo、临时签名和令牌查询参数，会话和凭据不得跨设备复用。
3. agent 只有在当前环境能够控制用户已登录页面时才接管。使用页面现有同源认证上下文调用 Web-only API；不要把会话秘密提取到脚本、命令行、案件文件、浏览器导出或聊天内容中。
4. 如果页面未登录、会话过期、设备身份不一致、浏览器工具无法接管或用户撤回授权，立即停止该页面的 API 调用并更新会话状态。可以让用户重新自行登录，但不能要求其提供凭据。
5. 如果没有可用浏览器控制能力，让用户保持页面打开，并改用用户执行页面内只读查看、脱敏截图/录屏或脱敏网络证据；不得假装 agent 已直接访问该 Web UI。

## 被动证据顺序

1. 记录准确型号、硬件版本、固件版本、Web UI 构建版本和访问时间。
2. 使用上述由客户打开、登录并明确允许只读诊断的现有认证页面；不绕过认证、不猜密码、不禁用安全控制。
3. 保存设备自己提供的 HTML/JS/CSS 资源哈希，在副本中搜索当前症状相关 UI 标签、命令枚举和调用点。
4. 被动观察页面初始加载、打开只读状态页或正常刷新产生的 WebSocket/HTTP 请求与响应。不要点击 Apply、Save、Pair、Reset、Upgrade 或其它可能写入的控件来发现协议。
5. 将固件观察结果与静态 API 文档和本地 IPAV/ODM 资料逐条比较，写入 `command-source-audit.csv`。

## 安全分级

- `documented_readonly`：适用静态文档明确只读，可按原规则执行。
- `firmware_observed_readonly`：同型号同固件 UI 在同一传输上自动发送该准确请求以读取状态；保存了调用点、请求、响应和无写入交互的证据。仅允许相同传输、相同参数形态的最小重放。
- `enumerated_unverified`：只在 SPA 字符串、枚举或未执行代码中出现。不能执行；命令名含 `GET` 也不改变该结论。
- `mutating_or_unknown`：SET/Apply/Save/Pair/Reset/Upgrade，或行为/参数不明。只登记；执行需准确语义、影响与回退，并获得具体授权。

WebSocket 观察不能推导 Telnet、SSH 或 HTTP 也支持相同字符串。若确需跨传输验证，必须另有该传输的文档或同固件被动行为证据。任何未知响应、设备重连、状态变化或异常负载迹象都要立即停止。

## 在已登录页面中调用 Web-only API

- 调用前重新核对页面同源地址、设备身份、固件/UI build、登录状态和用户只读授权；compacting 或长时间停顿后不能默认会话仍有效。
- 只重放该页面正常加载或只读刷新已经证明为状态读取的准确请求，并保持相同方法、路径/WebSocket 通道、参数形态和同源页面上下文。可以使用 Web-only API，不需要也不应寻找 Telnet 等价命令。
- 请求和响应证据必须脱敏后落盘，并关联 `web-ui-session-ledger.csv`、`command-source-audit.csv` 和 `progress-ledger.csv`。认证材料始终留在浏览器会话内。
- 页面按钮显示为“读取/刷新”也不是安全证明；如果调用可能触发 Apply、Save、Pair、SET、重启或任何状态变化，按写操作逐项征得授权。

## 命令集差异输出

每行记录命令、来源、固件、传输、静态文档是否存在、本地知识库证据、UI 枚举位置、被动调用证据、只读依据、验证状态和允许范围。静态文档缺失但满足 `firmware_observed_readonly` 的命令可以加入诊断目录；报告必须标注它不是静态 API 手册覆盖项。

写命令仍遵守逐项授权：说明准确目标、当前值、拟改值、预计影响、恢复方式和验证方法。Web UI 登录凭据、Cookie、授权头和握手秘密只在内存或现有会话中使用，所有持久证据必须脱敏。
